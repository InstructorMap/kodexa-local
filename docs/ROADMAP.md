# Roadmap

## Fase 1 — MVP demostrativo (actual)
- [x] Portal KODEXA Local.
- [x] Delivery: catálogo, carrito, pedidos demo, vistas de comercio y reparto.
- [x] Movilidad: solicitud, disponibilidad demo y tablero central.
- [x] Turnos: servicios, solicitud de turno y agenda demo.
- [x] Persistencia local por navegador.
- [ ] Pruebas de campo con usuarios piloto.

## Fase 2 — Diseño operativo
- [ ] Validación con comercios, centrales, profesionales y repartidores.
- [ ] Tarifas, responsabilidades, soporte y condiciones de servicio.
- [ ] Matriz de permisos y separación por tenant.
- [ ] Privacidad, retención y eliminación de datos.

## Fase 3 — Backend
- [ ] Modelo de datos Supabase/PostgreSQL.
- [ ] Auth y roles.
- [ ] RLS por tenant y producto.
- [ ] Funciones transaccionales y auditoría.
- [ ] Entornos de prueba y producción.

## Fase 4 — Piloto
- [ ] Piloto controlado de Delivery con comercios que acepten participar.
- [ ] Verificación legal, fiscal, laboral, seguros y habilitaciones aplicables.
- [ ] Monitoreo, soporte y plan de incidentes.

No se debe interpretar el prototipo como una plataforma operativa o como prueba de acuerdos con terceros.
